常用工具图标随仓库保存，统一使用 32 × 32 SVG 底座，适配浅色和深色背景。

品牌图形来自 [Simple Icons 16.34.0](https://github.com/simple-icons/simple-icons/tree/16.34.0/icons)，底座与配色按主页调整。`transformers.svg` 使用 Hugging Face 标识，`cuda.svg` 使用 NVIDIA 标识；`react-loop.svg` 和 `context.svg` 为 ReAct、上下文管理绘制的概念图标。

Simple Icons 图形按项目的 [CC0 协议](https://github.com/simple-icons/simple-icons/blob/16.34.0/LICENSE.md) 使用。
